# 脚本与分镜指南

从范例《中国古代四大发明》（4 分 14 秒，25 个场景，12 张知识卡）总结。

## 1. 旁白脚本（script.json）

**结构**（下表是范例的做法，作参考，不是硬性规定）：片头 → 3~5 章 → 结语。每章是一条叙事线，不是知识点罗列。

| 段 | 句数 | 时长 | 作用 |
|---|---|---|---|
| intro | 3 | ~25s | 第 1 句点题，第 2 句给意义，第 3 句「今天就让我们走进……」过渡 |
| 每章 | 6~7 | ~45-50s | 问题/背景 → 发明/发现 → 关键人物+年份 → 改进 → 传播/影响 |
| outro | 3 | ~25s | 总结 → 升华 → 收束一句 |

**章节字段**：`title` 用「一、造纸术」格式（章节卡会去掉「一、」）；`sub` 写「时代 · 人物」或「时代 → 时代」，如「唐 · 雕版 → 北宋 · 活字」。intro/outro 的 `key` 固定为 `intro`/`outro`。

**句子写法**（配音：ElevenLabs 女声，像央视纪录片解说）：
- 每句 3~10 秒，大约 15~45 字。一句只讲一件事
- 按逗号分开的小句尽量 ≤20 字（字幕按 ≤20 字切块）；超过 22 字 tts 脚本会告警
- 多用能被画出来的具体名词：「树皮、麻头、破布和旧渔网」比「多种原料」好画得多
- 年份、人名、书名要准确。用「据古籍记载」「考古发现表明」这类措辞区分史料和推断
- 避免「首先/其次/总之」这类演讲腔，以及英文缩写（TTS 会读错）
- 写完通读一遍，留意多音字。必要时换个同义词，别指望 SSML
- 中英双声（`voice_en`）：英文短语整段写（`two pieces of advice`、`Tom's book`），与中文间加空格；要逐个字母读就写大写加空格 `E S`、`I E S`（`es`/`-es`/`e-s`/`ES` 会被读成一个音节，像 "yes"）；单字母 `y`/`i`/`f`/`o`/`s` 照写即可
- 停顿：`sents` 里写数字（如 `2.5`）= 静音秒数，用于思考停顿/跟读停顿，一般 2~3 秒

## 2. 分镜（写 scenes.js 之前先列表）

每个场景覆盖 1~2 句，大约 8~12 秒；一章 4~5 个场景（范例做法，供参考）。先列出分镜表，再写代码：

```
场景  句子    画面                               锚点词 → 动作
p1    0-1     甲骨/青铜/竹简/缣帛四件依次落位       W('paper',0,'甲骨') 甲骨出现 …
p2b   3       蔡伦立像 + 四种原料图标环绕          W('paper',3,'树皮') 起逐个弹出
```

**原则**：
- **念到哪，画到哪**：每个具体名词、数字、人名都用 `W(章,句,'词')` 锚定，画面在这个词念出前约 0.2s 开始动
- **一屏一个主体**：主体居中偏上（字幕占底部 200px），配角和知识卡放左上或右侧
- **场景类型轮换**，别连着用同一种：物件特写 / 人物立像 / 工艺流程（箭头串联）/ 时间轴 / 地图传播路线 / 古籍竖排 / 夜景氛围
- **章内收尾**：每章最后一个场景尽量是「传播/影响」，用地图或时间轴，接到下一章的章节卡
- **全片骨架**：片头时间轴（总览全部主题）→ 各章 → 结语回收片头的元素，首尾呼应

## 3. 知识卡（fact）

每章 2~3 张，标签用 `史料` / `考古` / `知识点` / `馆藏`。内容要补充旁白**没说**的细节（出处、精确数字、名称由来），不要复述旁白。正文 ≤ 50 字，关键词用 `<em>` 标出。位置放左上 (70,130) 或右侧 (1380~1560, 100~650)，避开主体。卡片在句子中段出现，场景结束前收起。

## 4. 节奏与氛围

- 章节卡 4.6s 静音。`chapterCard(key,sealKey)` 在上一章 builder 末尾调用（`outro` 也要；主题负责动画，印章用 `asset(k,()=>makeSeal('字',60))` 注册）
- 背景氛围（如 ink 主题的远山透明度）用 `MOOD.push([t,v])` 关键帧调：章节卡时浓，讲解时淡，结语回浓。`t` 用 `SEC[k].card`/`SEC[k].start`/`S(k,i)` 加减偏移得到，不写死秒数
- 夜景/暗场用 `nightWin(t0,t1)` 标记（章节标签自动切深色）；该区间的知识卡传 `fact(…,dark=true)`
- 粒子、爆炸、烟火这类效果用 `addFX(t0,t1,draw)` 画在 canvas 上，不用 SVG 硬堆
